# 📷 틀린그림찾기 — 실사 이미지 레벨 추가하는 법

ChatGPT(또는 다른 AI)로 **거의 같은 사진 2장 + 다른 곳 좌표**를 만들어 이 폴더에 넣으면, 앱이 자동으로 **Lv6+ 실사 레벨**로 불러옵니다. (벡터 Lv1~5는 코드 내장이라 그대로 유지)

## 1) 이 폴더에 넣을 것
- 이미지 2장: 예) `room1_a.png`, `room1_b.png` (둘이 거의 같고, 정해둔 N곳만 다름)
- `manifest.json` 에 레벨 한 줄 추가

## 2) manifest.json 양식
```json
[
  {
    "title": "내 공부방",
    "a": "/spot_levels/room1_a.png",
    "b": "/spot_levels/room1_b.png",
    "diffs": [
      { "x": 0.30, "y": 0.20, "r": 0.06 },
      { "x": 0.72, "y": 0.35, "r": 0.06 },
      { "x": 0.50, "y": 0.66, "r": 0.05 },
      { "x": 0.18, "y": 0.80, "r": 0.06 },
      { "x": 0.85, "y": 0.75, "r": 0.05 }
    ]
  }
]
```
- `x`, `y` = **이미지 가로/세로 기준 0~1 비율** 위치 (왼쪽위 0,0 / 오른쪽아래 1,1). 다른 곳의 **중심**.
- `r` = 탭 허용 반경(가로 기준 비율, 기본 0.06 ≈ 6%). 작게 할수록 정확히 눌러야 함.
- 레벨을 여러 개 넣으면 위에서부터 Lv6, Lv7… 순서로 추가됨.

## 3) ChatGPT에 줄 프롬프트(복붙용)
> "공부방을 배경으로 한 **거의 똑같은 일러스트/사진 2장**을 만들어줘.
> 두 번째 그림에서 **딱 5곳만** 다르게 해(예: 시계 바늘 방향, 액자 그림, 컵 유무, 식물 꽃 색, 책 색).
> 그리고 다른 곳들의 위치를 **0~1 비율 좌표 (x,y)** 로 알려줘.
> ⚠️ 실제 사진/저작물 말고 **오리지널로 생성**해줘."

→ 받은 이미지 2장을 이 폴더에 저장하고, 알려준 좌표로 위 manifest 한 줄을 채우면 끝!

## 팁
- A·B 두 이미지는 **같은 크기**가 좋아요(세로 비율 동일).
- 처음엔 차이를 또렷하게(색·유무), 익숙해지면 미묘하게(작은 위치·명암).
